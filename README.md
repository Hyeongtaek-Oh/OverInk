# OverInk

화면 위에 바로 그리는 주석 도구입니다. 발표나 화면 공유 중에 강조하고 싶은 곳에 선을 긋고, 화살표나 도형을 그릴 수 있습니다.
평소에는 백그라운드에서 트레이 아이콘으로만 대기하다가 단축키 한 번으로 불러냅니다.

- 도구: 펜 · 형광펜 · 화살표 · 사각형 · 원 · 텍스트 · 지우개 (Shift 누른 채 펜 = 직선, 우클릭 드래그 = 지우개)
- 텍스트: 한글·영문·특수문자·이모지 등 유니코드 입력과 붙여넣기 지원
- 색: 기본 6색 + 최근 사용자 색, 색상 팔레트, 화면에서 색 추출(스포이드)
- 실행 취소 / 다시 실행, 전체 지우기, 그림 잠시 숨기기
- **투과 모드**: 그림은 화면에 남기고 클릭·키보드는 아래 앱으로 그대로 전달
- 펜촉 크기가 보이는 커서, 휠로 굵기 조절
- 모든 단축키를 설정 창에서 변경 가능

Python + PyQt6로 만들었고 **Ubuntu(X11)** 와 **Windows**에서 동작합니다.

## 설치

### Ubuntu

```bash
git clone https://github.com/Hyeongtaek-Oh/OverInk.git
cd OverInk
./install.sh --autostart
```

- 가상환경(`.venv`)을 만들고 의존성을 설치한 뒤 앱 목록에 등록합니다. Super 키로 `OverInk`를 검색하거나 독에 고정할 수 있습니다.
- `--autostart`를 붙이면 로그인할 때 백그라운드로 자동 실행됩니다. 앱 목록에만 등록하려면 빼고 실행하세요.
- `python3-venv` 패키지가 필요합니다: `sudo apt install python3-venv`
- 트레이 아이콘은 GNOME의 AppIndicator 확장(Ubuntu 기본 포함)으로 표시됩니다.

### Windows

1. [Python 3](https://www.python.org/downloads/)을 설치합니다 (설치 시 "Add python.exe to PATH" 체크).
2. 이 저장소를 받은 폴더에서 `install.bat`을 실행합니다. 로그인 시 자동 실행까지 원하면 명령 프롬프트에서:

   ```bat
   install.bat --autostart
   ```

시작 메뉴에 OverInk가 등록되어 검색하거나 작업 표시줄에 고정할 수 있습니다.
설치 후에는 폴더의 `run.bat`으로도 실행할 수 있고, 실행이 안 될 때는 `run.bat --debug`로 오류 메시지를 볼 수 있습니다.

### 등록 해제

```bash
./install.sh --uninstall      # Ubuntu
install.bat --uninstall       # Windows
```

바로가기와 자동 실행만 제거하며, 프로젝트 폴더와 설정 파일은 그대로 둡니다.

> 설치 스크립트는 프로젝트 폴더의 위치를 바로가기에 기록합니다. 폴더를 옮겼다면 설치 스크립트를 다시 실행하세요.

## 사용법

| 모드 | 설명 |
|---|---|
| 대기 | 화면에는 아무것도 없고 트레이 아이콘만 있음 (자동 실행 직후) |
| 그리기 | 마우스로 그림을 그림. 상단에 툴바 표시 |
| 투과 | 그림은 남기고 클릭·키보드는 아래 앱으로 전달 |

- **Ctrl+Alt+P** 또는 트레이 아이콘 클릭: 대기 → 그리기 / 그리기 → 대기 / 투과 → 그리기
- 그리기 모드에서 **Esc**: 투과 모드로 전환 (그림은 유지)
- 대기로 돌아가면 그림이 지워지지만, 다시 불러온 뒤 **Ctrl+Z**로 복구할 수 있습니다.
- 툴바는 왼쪽 `⋮⋮`를 잡고 끌어서 옮길 수 있고, 버튼에 마우스를 올리면 설명과 단축키가 표시됩니다.

### 텍스트 입력

텍스트 도구(**T**)를 고르고 글을 쓸 곳을 클릭하면 입력 상자가 뜹니다.

- 한/영 전환 등 평소 쓰는 입력기 그대로 입력하고, 특수문자·이모지는 입력기의 기호 입력이나 붙여넣기(Ctrl+V)로 넣을 수 있습니다.
- Enter는 줄바꿈, **Esc**나 바깥 클릭(또는 Ctrl+Enter)으로 입력을 마칩니다. 입력 중에는 그리기 단축키가 동작하지 않고 글자로 입력됩니다.
- 글자 색은 현재 색, 크기는 펜 굵기를 따릅니다(휠로 조절). 입력 중에 바꾸면 바로 반영됩니다.
- 완성된 글자는 다른 그림처럼 지우개·실행 취소·전체 지우기가 적용됩니다.

## 기본 단축키

툴바의 **⚙** 버튼이나 트레이 메뉴의 **단축키 설정…** 에서 모두 바꿀 수 있습니다.

**전역 단축키** — 다른 앱을 쓰는 중에도 동작

| 키 | 동작 |
|---|---|
| Ctrl+Alt+P | 그리기 시작 / 백그라운드로 숨기기 |
| Ctrl+Alt+C | 전체 지우기 |
| Ctrl+Alt+H | 그림 숨기기 / 보이기 |
| Ctrl+Alt+Q | 종료 |

**그리기 모드 단축키**

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| P | 펜 | 1 ~ 6 | 기본 색 |
| H | 형광펜 | 7 | 최근 사용자 색 |
| A | 화살표 | I | 스포이드 (Esc·우클릭으로 취소) |
| R | 사각형 | [ / ] | 펜촉 가늘게 / 굵게 |
| O | 원 | Ctrl+Z | 실행 취소 |
| T | 텍스트 | Ctrl+Shift+Z | 다시 실행 |
| E | 지우개 | Esc | 투과 모드로 전환 |
| C | 전체 지우기 | | |

고정 동작: 휠 = 굵기 조절, Shift + 펜 = 직선, 우클릭 드래그 = 지우개

## 설정 파일

단축키와 최근 사용자 색은 `~/.config/overink.json` (Windows: `%USERPROFILE%\.config\overink.json`)에 저장됩니다.
단축키는 기본값과 다른 것만 기록되며, 파일을 지우면 기본값으로 돌아갑니다.

## 알려진 제한

- Ubuntu는 **X11 세션**에서만 동작합니다. Wayland에서는 오버레이 창 배치와 전역 단축키가 제한됩니다.
- Ubuntu에서 fcitx 입력기를 쓰면, pip로 설치된 PyQt6에 fcitx용 플러그인이 없어 IBus 호환 방식으로 자동 연결합니다. fcitx5는 이 방식을 기본 지원하고, 구버전 fcitx4에서는 한글 입력이 안 될 수 있습니다.
- 전역 단축키는 [pynput](https://pypi.org/project/pynput/)을 사용합니다. 데스크톱의 다른 단축키와 겹치면 둘 다 실행될 수 있으니 설정 창에서 바꿔 주세요 (예: GNOME의 Ctrl+Alt+D는 바탕화면 보기).
